# Mini Sudoku (6x6)

Premium-feel browser puzzle game built with React + TypeScript + Vite + Tailwind.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Gameplay

- 6x6 Sudoku rules using digits 1-6.
- 2x3 subgrid constraints.
- Easy / Medium / Hard generation with guaranteed unique solution.
- Notes mode, hints, conflict highlighting, keyboard navigation, timer, local persistence.
